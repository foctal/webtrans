# Security Policy

## Supported versions

Security fixes are provided for the latest released minor version. Older minor
versions may receive a fix when the change can be backported safely, but this
is not guaranteed. Pre-release and unreleased revisions are supported only on
a best-effort basis.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it
privately by emailing `shellrow@foctal.com` with:

- the affected crate and version or commit;
- reproduction steps or a proof of concept;
- the expected impact;
- any suggested mitigation; and
- a secure way to contact you.

You should receive an acknowledgement within seven days. The report will be
triaged, its impact and affected versions will be assessed, and a remediation
plan will be shared when possible. Disclosure timing will be coordinated with
the reporter after a fix is available. Complex protocol or dependency issues
may require coordination with upstream maintainers.

Please allow a reasonable remediation period before public disclosure. Good
faith research and responsible disclosure are appreciated.
